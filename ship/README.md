# OpenLabel Static Prototype

This is the first shippable OpenLabel loop:

1. Paste or type a product, URL, or claim.
2. Get a seeded OpenLabel read.
3. Compare Current Offering Soul, Most Honest Offering Soul, alternatives, conviviality takeaways, reader panels, agentic-health survival, and compressed evidence.

Open directly:

`ship/index.html`

Seeded examples:

- BrainTap
- Healy
- Primal Trust

This is intentionally static. It does not run live research or model calls yet. The point is to test whether the user loop lands before building pipeline machinery.
